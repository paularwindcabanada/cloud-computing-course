# Cloud Concepts Reflection

Cloud computing has become part of my everyday life, even though I do not always notice it. Many of the applications I use every day depend on cloud technology to store data, share files, and provide online services.

Three cloud services I regularly use are Google Drive, Messenger, and Canva. Google Drive is a **Software as a Service (SaaS)** because I can store, edit, and share files directly through my browser without installing or managing any servers. It uses a **Public Cloud** deployment model since anyone can create an account and use the service online. Messenger is also a **SaaS** application because Meta provides the messaging platform while users simply access its features. It is also considered a **Public Cloud** service because it is available to the general public over the internet. Canva is another example of **SaaS** because it allows users to create designs online without worrying about the software or infrastructure behind it. Like the others, Canva operates on a **Public Cloud** since it is accessible to anyone with an internet connection.

Git and GitHub are also important when working on cloud projects. Version control keeps track of every change made to files, making it easier to review updates or restore an earlier version if something goes wrong. This helps prevent accidental mistakes from affecting the whole project. GitHub makes teamwork more organized because everyone can work on different tasks, share their progress, and combine changes without overwriting each other's work. It also provides a clear history of edits, making collaboration smoother and helping teams manage cloud resources more confidently and efficiently.
